# Project instructions

- Keep site content in `src/data/` when it is shared across pages. Product status and names must come from `src/data/products.ts`.
- Preserve the factual early-stage framing. Do not add invented customers, integrations, results, certifications, incorporation, partnerships, or product availability.
- Do not imply Anthropic endorsement or that a Claude integration exists.
- Keep the site static-first. Do not add a backend, tracking, a fake form, or secrets to client code.
- Use local assets and the system font stack. Do not add external font or image CDNs without a clear reason.
- Use semantic markup, keyboard-visible focus, reduced-motion support, and mobile layouts.
- Keep GitHub Pages output static, path-correct, and compatible with the repository base path.
- Before delivery, run the commands listed in the README and report any browser or environment limitation accurately.
