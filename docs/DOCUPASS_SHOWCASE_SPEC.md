# DocuPass visual showcase

## Outcome

Help visitors understand DocuPass from real desktop captures, a controllable animated screen tour, a synthetic scan-to-field comparison, and reproducible OCR evidence. Preserve the existing site layout, themes, system fonts and five languages.

## Requirements

- Larger product visuals, cleaner card hierarchy and more readable headings across the portfolio.
- DocuPass hero links directly to the demo and OCR results.
- Real local app screens with explanatory captions and original-size links.
- A short video assembled from real captures, labeled as a screen tour rather than a continuous recording; native playback controls and no autoplay.
- Synthetic receipt paired with observed merchant and total; downloadable sample and sanitized test report.
- Distinguish test pass, OCR confidence and accuracy; no invented percentage, GPU benchmark or customer data.
- Static site, local assets, keyboard controls, mobile stacking, light/dark contrast, reduced motion.

## Evidence

Run the packaged app's existing self-test on local synthetic PNG, HEIC, empty-file and receipt inputs. Record observed output and export checks. Screenshots use an isolated app data folder; no personal documents or account information.

## Verification

OCR test explicitly requested. Run repository lint, typecheck, build and existing checks; inspect desktop/mobile output and media. Publishing follows the user's existing GitHub update authorization.
